核心概念

双计算原语

FCT 仅依赖两种计算原语构建所有能力：门级函数承担计算，DSU 承担状态。 所有组件、所有证明路径、所有应用场景，都建立在这两个原语之上。

双原语的关键特性
原语 特性
门级函数无副作用：无法调用外部合约，无法写入外部状态
门级函数只读调用：不消耗 Gas，不产生交易
门级函数确定性：相同输入与状态，总是相同输出
门级函数可组合：一个函数可作为子模块被另一个函数引用，组合是结构性的
DSU可验证性：数据、证明、决议由客户端直接验证，无需信任第三方
DSU抽象性：不关心载体（链、链下存储、去中心化存储），只关心状态的可验证性

统一语言前端

GateLang v2.1 · 统一可验证计算语言前端

GateLang 以 NAND 门为唯一组合原语、LATCH 为唯一状态原语，通过四层抽象把开发者逻辑统一编译为 FCT 兼容产物。 其 spec 与 gateproof 生成形式化验证证明并与函数 / 容器 NFT 绑定；AI 辅助开发必须经 gatelang-ai-gate 强制验证 —— AI 是加速器，形式化验证是保证者。

技术组件

五类链上技术组件

FCT 的组件是协议无关的：它们不预设任何特定网络作为运行环境，而是通过适配器接入任意具备基础记账能力的网络。

执行 · Executable

门级函数（NAND + LATCH）与 DSU 共同承担计算：函数定义逻辑，DSU 定义状态接口。

状态 · State

容器（Container）封装节点状态，CSC 压缩状态承诺，历史默克尔树 + 扩展默克尔树 + 状态租金。

证明 · Provable

授权可重放、ZK 证明、TEE 证明三种路径并存，用户按安全需求自由选择。

清算 · Liquidatable

适配器负责跨链清算：状态根锚定 + 资产托管 + 最终仲裁，链的状态变化可被清算。

身份 · Identifiable

函数 NFT 与容器 NFT：门票、版税登记、管理员身份三位一体，来源可追溯。

载体无关

组件不依赖特定链，通过适配器接入 EVM、Solana、Cosmos、Move 与比特币 L2，逐链推进。

状态组件

容器 Container —— 节点状态的"盒子"

容器装载节点的状态与资产，是网络中可转让、可授权的核心载体： 转移令牌即转移管理权，持有者获得节点的一切访问权。

✓
可转让

一次性可转让令牌与不可转让令牌：转让令牌即转让容器所有权。

✓
资产装载

天然装载 ETH、ERC-20、ERC-721 资产，作为节点的经济实体。

✓
accessToken 授权

DSU 访问由 accessToken 控制，授权粒度灵活可撤销。

✓
私有状态承诺

内部状态以承诺公开，细节对外保密，验证与隐私兼得。

✓
管理员联动

容器的管理员跟随容器 NFT 的所有权 —— 谁持有 NFT，谁管理容器。

典型场景

AI 服务节点付费推理：调用方支付 ETHER，节点执行门级函数并返回结果，收入沉淀在容器中。
资产托管容器作为托管实体装载资产，状态根锚定到清算链，随时可清算。
状态租用CSC 状态租金按字节计价，长期闲置被回收，状态市场提供租金补助。

证明组件

证明市场 —— 计算可靠性的四条路径

以往只有「信任网络」或「信任应用」两种选择。FCT 提供第四种：客户端可以直接验证计算，无需信任任何人； 需要更强保证时，可组合 ZK 或 TEE 证明。

鉴权路径 信任假设 适用场景
公开可重放零信任（客户端重放验证）公共函数、开源验证器
仅授权重放持有 accessToken 即可验证私有、受限状态
授权 ZK信任密码学，链上验证证明n 个被引用函数的聚合证明
授权 TEE信任硬件制造商高吞吐、低延迟计算网络

DSU 可验证性

  • 数据、证明、决议三表合一，任何客户端均可直接验证状态更新
  • 被引用的函数网络自行承担证明费用 —— 主叫方只付一次原函数调用费
  • 证明市场包含：重放市场、ZK 证明市场、TEE 证明市场，可证明逻辑互联

经济模型

无代币 · 一切以 ETHER 结算

FCT 没有原生代币。它不发行、不预售、不空投任何资产 —— 经济媒介统一为 ETHER， 让组件的价值直接与链上资产绑定，不引入任何投机媒介。

统一 ETHER 结算

所有费用、版税、清算、租金的结算媒介都是 ETHER —— 无代币、无通胀、无投机。

组合版税

门级函数被引用或组合时，创作者获得 ETHER 版税，从调用方支付的费用中分成。

费用自理

被引用的函数网络自行承担证明费用，用户只需为自己的原函数调用付费。

反诈骗声明

FCT 无任何代币、预售或空投。任何声称是「FCT 代币」并出售、要求认购或空投的行为均为诈骗，请勿参与。
