计算无副作用 · 状态原子转移 · 逻辑状态机（LSM） 链上技术组件套件

FCT 不是一条链、不是一个代币、不是 L2 —— 它是 Ethercoin 团队维护的链上计算与状态技术组件套件。 FCT 提供的核心技术正式命名为逻辑状态机（Logical State Machine, LSM）：以 NAND 纯函数原语承担计算， 以 LATCH 状态原语承担记忆，组合部分为布尔函数，时序部分为有限状态机 —— 可在链上被调用，用于验证、条件求值和状态约束。

定位与边界

FCT 是什么，不是什么

FCT 是 Ethercoin 团队对外输出的链上计算与状态技术组件，不是一条独立的链，也不是一个代币项目。 Ethercoin 通过在各公链部署 FCT 适配器，规划成为各公链的 L2/侧链，提供类似跨链桥但更可验证的清算功能。

标准术语

为什么不再说「电路」「网表」「门级」

在软件 / 链上环境中，沿用硬件术语容易引入错误的硬件语义。GateLang 的编译产物不是硬件意义上的电路， 而是可执行逻辑-状态程序 / 逻辑状态机：组合部分为布尔函数，时序部分为有限状态机。

核心概念

双计算原语

FCT 仅依赖两种计算原语构建所有能力：逻辑原语函数承担计算，DSU 承担领域专用执行。 两者在可计算功能上均图灵完备、可相互模拟，但在形式化验证粒度、证明成本与性能特征上互补。

技术组件

五类链上技术组件

FCT 的组件是协议无关的：它们不预设任何特定网络作为运行环境，而是通过适配器接入任意具备基础记账能力的网络。

执行 · Executable

逻辑原语函数（NAND + LATCH）与 DSU 共同承担计算：函数定义逻辑，DSU 定义领域专用执行，两者共享容器状态层。

状态 · State

容器（Container）封装节点状态，CSC 压缩状态承诺，历史默克尔树 + 扩展默克尔树 + 状态租金，冷热状态分离。

证明 · Provable

重放证明、ZK 证明、TEE 证明三种路径并存，证明者与验证者解耦，用户按安全需求自由选择。

清算 · Liquidatable

适配器负责跨链清算：状态根双向锚定 + 资产托管 + 挑战期与保险基金，链的状态变化可被清算。

身份 · Identifiable

函数 NFT 与容器 NFT：门票、版税登记、管理员身份三位一体，来源可追溯，跨链登记。

载体无关

组件不依赖特定链，通过适配器接入 EVM、Solana、Cosmos、Move 与比特币 L2，逐链推进、独立可验证。

状态组件

容器 Container —— 节点状态的「盒子」

容器装载节点的状态与资产，是网络中可转让、可授权的核心载体： 转移令牌即转移管理权，持有者获得节点的一切访问权。容器属于那枚容器 NFT，其主人可以是人，也可以是 AI Agent。

✓
可转让

一次性可转让令牌与不可转让令牌：转让令牌即转让容器所有权。

✓
资产装载

天然装载 ETHER、稳定币、ERC-20、ERC-721 资产，作为节点的经济实体。

✓
accessToken 授权

DSU 访问由 accessToken 控制，授权粒度灵活可撤销。

✓
私有状态承诺

内部状态以压缩状态承诺叶子形式公开，细节对外保密，验证与隐私兼得。

✓
管理员联动

容器的管理员跟随容器 NFT 的所有权 —— 谁持有 NFT，谁管理容器。

证明组件

证明市场 —— 计算可靠性的四条路径

以往只有「信任网络」或「信任应用」两种选择。FCT 提供第四种：客户端可以直接验证计算，无需信任任何人； 需要更强保证时，可组合 ZK 或 TEE 证明。繁重计算在证明者侧完成，链上仅需低成本验证 —— 计算与验证解耦。

四条鉴权与证明路径
鉴权路径 信任假设 适用场景
公开可重放零信任（客户端重放验证）公共函数、开源验证器
仅授权重放持有 accessToken 即可验证私有、受限状态
授权 ZK信任密码学，链上验证证明n 个被引用函数的聚合证明
授权 TEE信任硬件制造商高吞吐、低延迟计算网络

证明市场与最终性

  • 证明者通过提供证明获得 ETHER 奖励；验证者通过验证证明获得手续费分成
  • 提交无效证明的证明者将被罚没保证金并永久失去资格
  • 状态转换证明被超过 2/3 验证者确认即达到最终性，预计达到秒级
  • GateLang 的 spec 与 gateproof 生成形式化验证证明，与函数 / 容器 NFT 绑定，调用者可在调用前验证

经济模型

无代币 · 一切以 ETHER 结算

FCT 没有原生代币。它不发行、不预售、不空投任何资产 —— 经济媒介统一为 ETHER， 让组件的价值直接与链上资产绑定，不引入任何投机媒介。

统一 ETHER 结算

所有费用、版税、清算、租金的结算媒介都是 ETHER —— 无代币、无通胀、无投机。

组合版税

逻辑原语函数被引用或组合时，创作者获得 ETHER 版税，从调用方支付的费用中分成。

费用自理

应用前景

LSM 可能催生的十类项目形态

如果预言机解决了「链上如何获取可信外部数据」，并催生了 Chainlink；那么逻辑状态机（LSM）解决的是 「链上如何以可验证、确定性、无副作用的方式执行逻辑和管理状态」。它可能催生的不是另一个数据网络，而是一个可验证逻辑与状态层。

逻辑状态机网络

类比 Chainlink。节点运行 GateLang 编译的逻辑状态机，为 dApp 提供只读验证、条件求值、合规检查和状态承诺验证服务。

跨链验证者市场

LSM-CCV 市场。第三方发布经形式化验证的跨链验证状态机，发行方按资产价值选择不同安全层级的验证程序。

合规状态机网络

面向机构级跨链与 DeFi。KYC/AML、制裁筛查、交易限额、白名单规则编译为逻辑状态机，与 CCIP 2.0 的 ACE 集成。

函数 NFT / 容器 NFT 市场

链上逻辑的 App Store。开发者将验证函数、金融策略、游戏规则、保险理赔条件编译为 LSM，以函数 NFT 形式发布。

跨链状态协同协议

不是资产桥，而是状态桥。源链 LSM 输出状态根，目标链 LSM 验证并执行对应状态转移。

意图求解器网络

用户表达意图，LSM 定义条件，求解器竞争执行。可用于跨链交换、限价单、自动再平衡、保险自动理赔。

可验证 AI 代理网络

AI 是加速器，形式化验证是保证者。LSM 作为 AI 代理行为的约束层：AI 提出的操作必须满足预设状态机规则。

状态租金与状态压缩协议

CSC + 历史默克尔树 + 扩展默克尔树。只验证状态根，不展开完整状态，降低全节点存储负担与状态膨胀。

治理与权限状态机

针对 DAO 治理攻击与配置失误。治理规则、多签门槛、时间锁、权限转移编译为 LSM，高权限操作必须满足预设状态转移序列。

形式化验证即服务（FVaS）

将业务规则自动编译为 LSM 并生成证明。从 Solidity、DSL 或自然语言自动生成逻辑状态机并输出验证报告。

「数据 + 逻辑 + 状态」的模块化区块链栈

最可能诞生的是「逻辑状态机网络」—— 一个与 Chainlink 并列的基础设施层。Chainlink 提供「数据可用性」，LSM 提供「逻辑与状态的可验证性」。两者结合 CCIP 2.0，可形成「数据 + 逻辑 + 状态」的模块化区块链栈。

规范的逐步落地

  1. 2026FCT 规范与双原语组件开发
    • FCT 技术组件 v1.4 进入规范与开发阶段，发布双原语规范与技术组件白皮书
    • GateLang v2.2 作为统一语言开发工具集成；逻辑原语函数、DSU、容器、CSC、证明市场组件化
    • 在 Sepolia 测试网完成组件级验证与集成测试

    当前进度：M1 容器 · M2 CSC · M3 证明市场 · M4 共享层 · M5 逻辑原语引擎 + DSU 执行引擎 · M6 混合模式 · M7 跨链适配器已在 Sepolia 上线并完成链上验证

  2. 2027以太坊适配器 + Robinhood Chain
    • 以太坊适配器独立审计后部署主网清算 / 验证器；身份锚定、函数 NFT、状态根验证
    • Robinhood Chain（Arbitrum Orbit + Nitro）近乎零成本迁移，约 100ms 出块
    • 优先费完全转化为创作者版税；面向 RWA 的股息计算与合规检查函数
  3. 2028Solana 适配器
    • 逻辑原语函数编译为 BPF 只读纯计算程序，Groth16 证明经 alt_bn128 syscalls 链上验证
    • 通过 Rome Protocol 与 EVM 生态共享状态；利用 Sealevel 并行执行
  4. 2029+多链清算自治
    • EVM、Solana、Cosmos、Move、比特币 L2 全适配
    • 跨链函数调用、跨链版税、DAO 治理与清算自治运转

以上为架构规划。FCT 链尚未激活，FCT 未发行任何代币。每一步都独立可验证，某一步遇到技术障碍时前一步成果不会作废。

让链上计算成为架构的属性

以逻辑原语承担计算，以容器承担状态，以 ETHER 结算价值 —— FCT 是一套供任何网络集成的技术组件，安全由架构保证，而非应用层代码的质量。
